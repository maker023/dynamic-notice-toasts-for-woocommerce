Triple-Vector Notice Interception Engine

Guarantees zero Cumulative Layout Shift (CLS) across classic templates, block checkouts, and 3rd-party AJAX

01

Server Interception (PHP)

Hooks into template_redirect and woocommerce_output_all_notices at Priority 1.

  • Extracts notices via wc_get_notices()
  • Calls wc_clear_notices() immediately
  • Suppresses wrapper via wp_head CSS
  • Serializes payload into localized JS
02

AJAX Interception (JS)

Listens directly on WooCommerce jQuery document triggers and native AJAX pipelines.

  • added_to_cart (Add to Cart events)
  • checkout_error (Validation errors)
  • applied_coupon / removed_coupon
  • Global ajaxSuccess failure parser
03

DOM MutationObserver

Catches rogue notices appended directly to the DOM by external payment gateways or custom themes.

  • Monitors .woocommerce-notices-wrapper
  • Sets display: none !important
  • Parses inner HTML & action links
  • Spawns toast with zero latency

Intelligent Action Link Decoupler

WooCommerce frequently packs raw <a class="button wc-forward">View cart</a> anchors directly inside plain notice text strings. The Toast Engine parses and decouples them:

Standard WooCommerce Output:
<div class="woocommerce-message"><a href="/cart/" class="button">View cart</a> “Shirt” has been added to your cart.</div>
Toast Engine Output:
Clean Body: “Shirt” has been added to your cart.
Action Button: View cart →

Data Sanitization & Late Escaping

PHP 7.4 through 8.3 Verified
Zero syntax errors, full backwards compatibility, strict types where supported.
