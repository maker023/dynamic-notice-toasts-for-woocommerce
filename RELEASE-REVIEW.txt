IMPLEMENTED
- Four supplied palettes, used by all four layouts.
- Margin Note, System Capsule, Retro Outline, and Status Canvas on the storefront.
- 24 optional color-token overrides beside a live preview in WordPress.
- Standalone design lab with the same styling engine, editable tokens, reset and JSON export.
- Palette/layout-specific defaults, with user overrides taking precedence.
- Latest layout refinements: 20px Margin Note padding, filled close control, text-only action hover;
  charcoal/white buttons for Lime System Capsule only; transparent bordered Retro symbols,
  filled close controls and 8px/6px gaps; compact Status Canvas padding and <=36px icons.
- Documented PHP filters, CSS tokens, JavaScript API and browser lifecycle events.
- Safe notice HTML/URL handling, validated token allowlist, nonce/capability-protected saves.
- Keyboard-focus timer pause, optional banner suppression, and footer delivery deduplication.
- WordPress.org readme, GPL/MIT/OFL licenses, POT template, build tools and CI checks.
- Submission text-domain correction: translation calls, header, POT, WPCS and Plugin Check
  now use dynamic-notice-toasts-for-woocommerce, matching the submission scan.
- Directory icons, banners, screenshots and a live-preview Blueprint in .wordpress-org/.

REPRODUCE
1. composer install && npm ci
2. composer lint
3. npm run check:js && npm run test:unit
4. npm run build
5. On Windows: npm run review:setup && npm run review:native
6. npm run preview -- --port=9410, then npm run test:browser
7. Native review regenerates the POT file; run npm run build again afterwards.

TESTING SCOPE
- This is not a full matrix of every WordPress/PHP/WooCommerce version, browser or third-party theme.
- SQLite was used for the local integration fixture. CI is configured for WordPress Plugin Check's wp-env environment.
- Classic WooCommerce notice handling was exercised; broad Cart/Checkout Blocks compatibility is not declared.
  Test your actual checkout, payment/shipping extensions, mobile devices and screen readers on staging.
- Custom colors are validated as colors, but contrast depends on the chosen combination.
  Automatic foreground selection prefers the higher-contrast palette color; it does not guarantee WCAG conformance.
